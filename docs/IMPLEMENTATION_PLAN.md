## Результат этапа 5 — 11 октября 2026

- Подписка реализует `Postable`: один расход итоговой суммы в `CustomerAccount` и приход
  по каждой строке в новый `Revenue` — `TURNOVER` с измерениями тариф/клиент и ресурсами
  сумма/периоды. Onno создал таблицу движений выручки из метамодели — одно изменение схемы.
- `BeforePostHandler` проверяет средства через типизированный `CustomerAccountRepository`
  и возвращает русское сообщение. Для перепроведения учитывается возврат прежнего
  активного списания этой подписки; неактивные движения и чужой клиент не учитываются.
  Окончательную защиту от отрицательного остатка выполняет Onno внутри транзакции.
- Отменённая подписка (`CANCELLED`) не создаёт финансовых движений. Отмена проведения
  возвращает списание и убирает выручку; перепроведение заменяет оба регистра атомарно.
