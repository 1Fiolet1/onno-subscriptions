## Адаптация для отдельного проекта

В `onno-crm-adopt/SKILL.md` относительная ссылка `../../../onno-crm-channels-starter/README.md` заменена прямой ссылкой на тот же файл в GitHub на зафиксированном коммите. Остальные файлы сохранены без изменений.

Основные правила для приложения и выбор скиллов по задачам описаны в [AGENTS.md](../AGENTS.md). Инструкции из скиллов о работе с исходными модулями Onno применяются к соответствующим репозиториям; API приложения проверяется по фактически установленной версии библиотеки.

## Использование

Codex обнаруживает скиллы в `.agents/skills` проекта. Для явного выбора можно написать, например: «Используй onno-posting для проведения платежей и подписок». При подходящей задаче агент также может выбрать скилл самостоятельно.

Это инструкции и справочники для агента. Они не подключают зависимости Onno к приложению и не запускают PostgreSQL.

## Обновление

Перед обновлением проверь новый состав каталога `onno-plugin/skills/` в официальном репозитории и совместимость с версией Onno в приложении. Сохрани новый номер коммита, используй стандартный `skill-installer` с `--dest .agents/skills` и перенеси всю структуру справочников. Установщик не перезаписывает существующие каталоги: сначала подготовь новый набор отдельно и сравни изменения. Повторно адаптируй ссылку на руководство каналов, если в новой версии она остаётся относительной, и проверь обнаружение скиллов Codex.
